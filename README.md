# Trupti Naik — Professional Portfolio

A responsive, single-page portfolio for Ireland-based recruiters and hiring teams. Built with plain HTML, CSS and a small amount of JavaScript; no build step or paid framework is required.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `Trupti_Naik_Resume.pdf` — CV download linked from the homepage (if included)

## Preview locally
Open `index.html` in a browser. For best results, use a modern browser with an internet connection (Google Fonts are loaded remotely; fallback fonts are provided).

## Publish free using Netlify Drop
1. Sign in or create an account at https://app.netlify.com/
2. Keep `index.html`, `style.css`, and the CV PDF together in the same folder.
3. In Netlify, open the team Projects page and find the manual deploy / drag-and-drop area, or visit https://app.netlify.com/drop.
4. Drag the **folder containing the site files** onto the drop area. If the interface requests a folder of files, upload the extracted `trupti-portfolio` folder, not the ZIP file.
5. Netlify will publish the static site and provide a `*.netlify.app` URL. Open the URL and test all navigation and the CV download.
6. To update the site, edit the files and drag the updated folder into the site's Deploys page.

Alternative: publish via GitHub Pages. Create a public repository, upload `index.html`, `style.css` and the CV PDF to its root, then go to Settings → Pages and select deployment from the `main` branch / root. See https://docs.github.com/en/pages/quickstart.

## Before publishing — please review
- Confirm your preferred phone/email and whether you want your phone number displayed publicly. The page currently links email and LinkedIn but does not publish your phone number.
- Confirm the CV PDF filename is exactly `Trupti_Naik_Resume.pdf`. Replace it with your final public CV if you update your résumé.
- Review job title, dates, award names, and the metrics against your current CV.
- Do not add confidential customer details, proprietary logs, internal screenshots, or customer-identifiable information.
- LinkedIn profile link is set to https://www.linkedin.com/in/truptiriteshnaik/
- This portfolio does not claim a live deployment; publish it yourself using the steps above.
